Daily AI Open-Source Digest — March 23, 2026

Created2026-03-23|Updated2026-03-23|AI & Automation
|Post Views:
English edition, translated and edited from the Chinese article. Figures and product details refer to the original publication date. 中文原文

Tracking AI open-source projects over a 24-hour period, with operational automation based on OpenClaw.

Today’s top three

1. free-video-downloader

An AI video downloader and summarizer.

Stars recorded in the original roundup: 20.

Stack: Vue 3, FastAPI, yt-dlp, DeepSeek and Stripe.

Features highlighted in the original article:

  • Video downloads from more than 1,800 platforms.
  • AI-generated video summaries.
  • Mind-map generation.
  • International payments through Stripe.

GitHub

2. opencode-lazy

A plugin manager for OpenCode.

Stars recorded: 4. Stack: TypeScript.

  • Search for plugins online.
  • Install and manage plugins.
  • Work with plugins directly inside a session.

GitHub

3. free-llm-api-keys

A repository described in the original roundup as a collection of free LLM API resources.

Stars recorded: 4.

The original listing advertised free keys, three to five updates per day, support for GPT-5.4, Claude, DeepSeek, Gemini and Grok, and access without a credit card.

GitHub

Observations

The original roundup identified three themes:

  1. AI and video processing: combining downloads with AI summaries.
  2. Developer productivity: demand for plugin-management tools.
  3. API aggregation: interest in free LLM resources.

The original article attributed its selection to GitHub Trending over the preceding 24 hours, under the AI topic.
